SHIV PADULE PORTFOLIO — QUICK SETUP

1. Open this folder in Visual Studio Code.
2. Double-click index.html to preview the website in your browser.
3. Add your own MP4 videos inside the assets folder and name them:
   project-01.mp4, project-02.mp4, project-03.mp4
4. Optional: add thumbnail images named project-01-cover.jpg, project-02-cover.jpg, project-03-cover.jpg.
5. In index.html, replace:
   - 91YOURNUMBER with your WhatsApp number including country code (digits only; India = 91...)
   - YOUREMAIL@example.com with your real email address.
6. Update project titles/descriptions to match your real work.
7. To publish free: create a PUBLIC GitHub repository named username.github.io
   (replace username with your exact GitHub username), upload index.html,
   style.css and the assets folder, then enable GitHub Pages from Settings > Pages
   using Deploy from a branch > main > /(root).
8. Your site URL will be https://username.github.io/

IMPORTANT:
- Do not upload client-confidential or unapproved footage.
- GitHub Pages sites are public. Do not put private details in the repository.
- The portfolio template uses Google Fonts from the internet; the layout still works if fonts do not load.
